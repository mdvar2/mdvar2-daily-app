# CareerLane

## Description

CareerLane is a job application tracker designed for students and early-career developers who want a simple way to manage their job search. A Board represents a job-search campaign, such as graduate or junior developer applications. Columns represent stages in the application process, such as Interested, Applied, Assessment, Interview, Offer and Rejected. Cards represent individual job applications and can store details such as the company name, job title and important dates.

## Purpose

The purpose of CareerLane is to help students and early-career developers organise their job applications in one place. Managing several applications at the same time can make it difficult to remember which opportunities have been applied for and what stage each application has reached.

CareerLane aims to provide a clear workflow for following an application from initial interest through the application, assessment and interview stages to an offer or rejection.

## Setup

The CareerLane repository currently contains the project planning and documentation.

To access the project locally:
1. Make sure Git is installed.
2. Open a terminal and clone the repository:
```bash
git clone https://github.com/mdvar2/mdvar2-daily-app.git
```
3. Move into the project directory:
```bash
cd mdvar2-daily-app
```
4. Open the repository in your preferred code editor. For Visual Studio Code:
```bash
code .
```
5. Review `README.md`, `NOTES-mdvar2.md`, and the documentation under the `docs/` directory.

No application dependencies need to be installed at the current stage because the CareerLane application source code has not yet been added to the repository.

## Usage

CareerLane is being designed to allow a job seeker to:
- Create job-search boards for different job-search campaigns.
- View existing job-search boards.
- Rename an existing board without losing its applications.
- Add job applications to a selected board.
- Track applications through Interested, Applied, Assessment, Interview, Offer and Rejected.
- View the current stage of each application.

At the current project stage, the repository is used to manage and review the planning and documentation for these features.
