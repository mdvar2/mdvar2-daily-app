# CareerLane Product Backlog

## Application Boards
- Create a new job-search board with a board name.
- View all existing job-search boards.
- Rename an existing job-search board.
- Delete a job-search board.

## Application Tracking
- Add a new job application card to a board.
- Display job application cards in their current application stage.
- Move an application card between Interested, Applied, Assessment, Interview, Offer and Rejected.
- Remove a job application card from a board.

## Application Details
- Record the company name and job title for an application.
- Record the date an application was submitted.
- Record an application deadline.
- Add notes to a job application.

## Reminders
- Add an assessment date to an application.
- Add an interview date to an application.
- Provide reminders for upcoming important dates.
