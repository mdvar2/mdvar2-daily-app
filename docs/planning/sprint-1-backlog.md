# CareerLane Sprint 1 Backlog

## Sprint Goal
Create the basic Application Boards functionality so that a user can create, view and rename job-search boards.

## Ready Backlog Items

### Create a new job-search board
**Purpose:** Allow the user to create a board for organising a job-search campaign.

**User action:** The user chooses to create a new board and enters a board name.

**Required information:** A board name. If no name is entered, the board will automatically be named "Untitled Board".

**Acceptance criteria:**
- The user can create a new board.
- The board is saved with the name entered by the user.
- If the user does not enter a name, the board is created as "Untitled Board".
- The newly created board can be viewed after it is created.

**Blockers:** None.

### View all existing job-search boards
**Purpose:** Allow the user to see the job-search boards they have created.

**User action:** The user opens the boards section to view their existing boards.

**Required information:** Existing saved boards.

**Acceptance criteria:**
- All existing boards are displayed.
- Each board displays its name.
- A newly created board appears in the list of boards.

**Blockers:** None.

### Rename an existing job-search board

**Purpose:** Allow the user to change the name of an existing board.

**User action:** The user selects an existing board and changes its name.

**Required information:** The selected board and the new board name.

**Acceptance criteria:**
- The user can select an existing board to rename.
- The user can enter a new name.
- The new board name is saved.
- The updated name is displayed when the boards are viewed.

**Blockers:** None.

## Item Not Ready for Sprint 1

### Delete a job-search board
I wanted to include deleting a board in Sprint 1, but it does not currently meet my Definition of Ready. It is not yet clear what should happen to the job application cards inside a board when the board is deleted. This needs to be decided before the item can be included in a sprint.
