# CareerLane Sprint 1 Review

## Sprint Goal

Enable job seekers to create and manage a basic job-search board where they can add applications and clearly see their current progress.

## Sprint Progress

Sprint 1 contains five user stories with a total estimate of 17 story points. At the time of this review, two stories are In Progress and three are still To Do.

The two stories currently In Progress are:
- Creating a named job-search board.
- Renaming an existing job-search board.

The remaining stories are:
- Viewing all existing job-search boards.
- Adding a new job application to a board.
- Viewing each application in its current application stage.

## What Is Currently Demoable

The sprint is still in progress, so the complete Sprint Goal cannot honestly be demonstrated yet. The current work that can be shown is the planned CareerLane board workflow, including the user stories, acceptance criteria, dependencies, story-point estimates and the progress of the sprint through the workflow states. The create-board story has also been broken into smaller implementation tasks for creating the board input form, validating the board name and applying the default "Untitled Board" name when no name is entered.

## Sprint Goal Check

The Sprint Goal has not been fully achieved yet. The foundation for creating and managing job-search boards is in progress, but the application tracking stories still need to be completed before the full outcome can be demonstrated. The next focus should be completing the board stories and then progressing the application tracking stories so that a user can add an application and see its current stage.
